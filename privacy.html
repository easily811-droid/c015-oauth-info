C015 Video Inventory 隱私說明

適用範圍

C015 Video Inventory 使用 YouTube API Services，供單一操作者在本機整理影片、處理字幕及連接 YouTube。本說明分別介紹 Google 授權資料與來源素材處理資料。

Google 授權資料

Google 授權流程會取得執行 YouTube 功能所需的權杖。工具請求 YouTube 上傳與唯讀權限，使用 API 回傳的頻道識別資料確認目的頻道，並使用影片 ID、標題、說明及狀態資料處理選定影片的上傳與讀回核對。

登入與授權請求由 Google 處理。執行 YouTube 操作時，Google 會收到必要的 API 請求；上傳時也會收到選定影片與提交的發布資料。

Google 隱私權政策：https://policies.google.com/privacy

來源素材與模型處理資料

剪輯工作資料可能包含來源影片與音訊、來源網址、選段時間、逐字稿、字幕、標題、說明與審查紀錄。這些是用來製作及核對片段的素材，與上述 Google 帳戶權杖及 API 回應資料分開說明。

啟用模型處理步驟時，工具可能將來源逐字稿、選段字幕或相鄰脈絡交由設定的模型服務處理，並在本機保存相關輸入與結果。操作者應在執行該步驟前檢查內容及服務設定。這份說明沒有對所有外部服務的保存或訓練行為作保證。

本機存放、存取與紀錄

媒體、字幕、工作檔及操作紀錄存放於本機工作資料夾。刷新權杖使用 Windows CurrentUser DPAPI 加密存放；OAuth client 設定也是本機檔案。這不代表所有工作檔或備份都採用同一種加密方式。

能使用該 Windows 帳戶或具有相應資料夾權限的人，可能存取本機工作資料。備份副本也須由操作者管理。

操作與診斷紀錄可能包含頻道或影片 ID、來源網址、時間、檔案參照、雜湊、執行結果及審查資訊。已實作的安全 OAuth 診斷使用經篩選的狀態與原因欄位，不保存該流程的原始錯誤回應。

資料查詢、保留與刪除

如需詢問本機資料或提出刪除要求，請透過下列聯絡方式聯繫維護者。本機檔案及可控制的備份需由操作者確認後手動處理；提出要求不等於資料已完成刪除。

刪除資料時，應一併檢查原始檔、工作檔、輸出、API 資料紀錄與備份。刪除單一輸出不代表其他副本已清除。本工具目前沒有在此承諾固定保存期限或自動清除所有副本。

撤銷 Google 存取

你可以在 Google 安全性設定中撤銷應用程式的存取：https://security.google.com/settings/security/permissions

撤銷授權不會自動清除已保存的本機權杖檔、API 資料紀錄、來源素材或備份，這些仍需另行處理。已上傳至 YouTube 的影片也需在 YouTube 中管理；本機檔案刪除與遠端影片刪除是不同動作。
